# Доска объявлений с геолокацией — продолжение исходного проекта

Этот архив является **доработкой предыдущего проекта регистрации и авторизации**, а не новым проектом.

## Добавлено

- разграничение прав `user` / `admin` на сервере;
- личный кабинет;
- единый роутер через `public/index.php`;
- красивые маршруты через `public/.htaccess`;
- списки объявлений, категорий и городов из MySQL/MariaDB;
- административная панель;
- список пользователей;
- модерация объявлений;
- запись действий модерации в `ad_moderation_history`;
- сохранены PDO, prepared statements, хеширование паролей и CSRF-защита.

## Запуск

1. Расположить папку `doska_auth` в `C:\xampp\htdocs\`.
2. Запустить Apache и MySQL/MariaDB.
3. Использовать ранее импортированную БД `doska_obyavleniy` с таблицами из проекта.
4. Открыть:
   `http://localhost/doska_auth/public/`
5. Если красивые маршруты не работают, убедиться, что Apache разрешает `.htaccess` (`mod_rewrite` и `AllowOverride All`).

## Основные маршруты

- `/` — главная;
- `/login` — авторизация;
- `/register` — регистрация;
- `/logout` — выход;
- `/cabinet` — личный кабинет;
- `/ads` — список активных объявлений;
- `/categories` — категории;
- `/cities` — города;
- `/admin` — панель администратора;
- `/admin/users` — пользователи;
- `/admin/ads` — модерация объявлений;
- `/admin/categories` — категории администратора.

## Права

`user` не имеет доступа к `/admin/*`. Проверка выполняется на сервере функцией `require_admin()`, поэтому скрытия ссылки недостаточно для обхода ограничения.
