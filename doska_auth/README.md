# Доска объявлений с геолокацией — продолжение исходного проекта

Этот архив является **доработкой предыдущего проекта регистрации и авторизации**, а не новым проектом.

## Добавлено

- разграничение прав `user` / `admin` на сервере;
- личный кабинет;
- единый роутер через `public/index.php`;
- красивые маршруты через `public/.htaccess`;
- списки объявлений, категорий и городов из MySQL/MariaDB;
- административная панель;
- список пользователей;
- модерация объявлений;
- запись действий модерации в `ad_moderation_history`;
- сохранены PDO, prepared statements, хеширование паролей и CSRF-защита.

## Запуск

1. Расположить папку `doska_auth` в `C:\xampp\htdocs\`.
2. Запустить Apache и MySQL/MariaDB.
3. Использовать ранее импортированную БД `doska_obyavleniy` с таблицами из проекта.
4. Открыть:
   `http://localhost/doska_auth/public/`
5. Если красивые маршруты не работают, убедиться, что Apache разрешает `.htaccess` (`mod_rewrite` и `AllowOverride All`).

## Основные маршруты

- `/` — главная;
- `/login` — авторизация;
- `/register` — регистрация;
- `/logout` — выход;
- `/cabinet` — личный кабинет;
- `/ads` — список активных объявлений;
- `/categories` — категории;
- `/cities` — города;
- `/admin` — панель администратора;
- `/admin/users` — пользователи;
- `/admin/ads` — модерация объявлений;
- `/admin/categories` — категории администратора.

## Права

`user` не имеет доступа к `/admin/*`. Проверка выполняется на сервере функцией `require_admin()`, поэтому скрытия ссылки недостаточно для обхода ограничения.


## CRUD объявлений

Ключевая сущность проекта — объявление (`ads`). Реализованы полный цикл CRUD и обработка ошибок:
- Create: `/ads/create` — создание объявления авторизованным пользователем;
- Read: `/ads` и `/ads/view?id=...` — список и карточка объявления;
- Update: `/ads/edit?id=...` — изменение только собственного объявления;
- Delete: `/ads/delete` — логическое удаление со статусом `deleted`;
- серверная валидация полей, проверка CSRF, проверка прав владельца, обработка ошибок БД;
- после создания/изменения объявление получает статус `pending` и передаётся администратору на модерацию.


## Обновление интерфейса

- административная панель оформлена в едином стиле: обзорные карточки статистики, навигация по разделам и быстрые действия;
- страницы пользователей, категорий и модерации получили адаптивные таблицы, визуальные статусы, поясняющие блоки и сообщения для пустых списков;
- на административных страницах добавлена кнопка «Выйти»;
- форма создания/редактирования объявления разделена на логические блоки, дополнена подсказками по полям, оформлением координат и заметкой о модерации;
- исправлено подключение CSS для вложенных маршрутов `/admin/users`, `/admin/ads`, `/admin/categories` и `/ads/create`.
