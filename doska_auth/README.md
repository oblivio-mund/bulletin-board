# Доска объявлений с геолокацией — текущая версия проекта

Этот архив — доработка предоставленного проекта `doska_auth`. Исходная структура, авторизация, CRUD объявлений, личный кабинет и административная панель сохранены.

## Возможности

- регистрация и авторизация, хеширование паролей, PDO и подготовленные запросы;
- роли `user` и `admin` с серверной проверкой прав;
- личный кабинет и CRUD объявлений;
- детальная страница объявления с автором, категорией, стоимостью, статусом, городом, координатами и ссылкой на карту OpenStreetMap;
- поиск активных объявлений по названию и описанию;
- фильтры публичного каталога по категории, городу и диапазону цены;
- географический поиск по широте, долготе и радиусу от 1 до 500 км;
- сортировка по дате публикации и цене, постраничный вывод;
- административный список всех объявлений, включая черновики, ожидающие проверки, активные, отклонённые, архивные и удалённые записи;
- поиск в административном списке по названию, описанию и данным автора;
- фильтрация административных записей по статусу, категории и городу;
- детальный просмотр объявлений из административного списка;
- модерация объявлений с комментарием и записью действий в `ad_moderation_history`;
- CSRF-защита форм, серверная валидация и обработка ошибок подключения/запросов к БД;
- адаптивное оформление форм, фильтров, карточек и административных таблиц.

## Запуск в XAMPP

1. Распакуйте папку `doska_auth` в `C:\xampp\htdocs\`.
2. Запустите Apache и MySQL/MariaDB.
3. Используйте базу данных `doska_obyavleniy`, совместимую с таблицами из `database.sql`. Перед повторным импортом проверьте содержимое SQL: скрипт пересоздаёт таблицы и удаляет данные существующей схемы.
4. Проверьте настройки подключения в `config/config.php`: хост, порт, имя базы данных, пользователь и пароль.
5. Откройте `http://localhost/doska_auth/public/`.
6. Для красивых URL должен быть разрешён `mod_rewrite` и обработка `.htaccess` (`AllowOverride All`).

## Основные маршруты

- `/` — главная;
- `/login`, `/register`, `/logout` — авторизация, регистрация и выход;
- `/cabinet` — личный кабинет;
- `/ads` — каталог с поиском и фильтрацией;
- `/ads/view?id=1` — детальная страница объявления;
- `/ads/create`, `/ads/edit?id=1`, `/ads/delete` — CRUD объявления;
- `/categories`, `/cities` — справочники;
- `/admin` — обзорная панель администратора;
- `/admin/users` — список пользователей;
- `/admin/ads` — полный список объявлений, фильтры и модерация;
- `/admin/categories` — управление категориями.

## Проверка реализованных функций

1. Откройте `/ads`. Введите часть названия в поле поиска, выберите категорию/город, укажите диапазон цены и примените фильтры.
2. Для географического поиска заполните широту, долготу и радиус в километрах. Например, для проверки можно ввести координаты `55.7558` и `37.6173` с радиусом `25` км.
3. Нажмите «Подробнее» на карточке активного объявления. На детальной странице доступны сведения об объявлении, авторе, цене и местоположении.
4. Войдите учётной записью администратора и откройте `/admin/ads`. Проверьте поиск по объявлению/автору и фильтры по статусу, категории и городу.
5. В административной таблице нажмите «Подробнее» для открытия полной карточки. Для записей, которые ещё не удалены, можно выбрать решение модератора и при необходимости указать комментарий.
6. Попробуйте открыть `/admin/ads` от имени обычного пользователя — доступ должен быть запрещён серверной проверкой роли.

## Примечания

- Публичный каталог показывает только объявления со статусом `active`.
- Автор может просматривать собственные записи в других статусах; администратор может просматривать записи всех статусов.
- Удаление объявления является логическим: запись сохраняется в БД со статусом `deleted` и остаётся видимой в административном списке.
- Для поиска по радиусу используются координаты из поля `ads.location` и функция MariaDB `ST_Distance_Sphere`. Если функция недоступна в установленной версии MariaDB, используйте поиск по текстовым фильтрам или обновите СУБД до версии, поддерживающей эту функцию.
- Геолокация зависит от корректно сохранённых координат объявления. Широта и долгота вводятся в десятичных градусах.
